Values and variables 值和变量

  • val(value) 声明一个只读变量
  • var(variable) 声明一个可变变量
  • const(with val) 用于编译时已知的变量

e.g.

1

    val language = "kotlin"

val 不可变，可读性更强，尽可能使用 val

val 可以赋值给 var

常量不能直接被赋值修改，但是可以通过其他方式修改内容。

val 与Java中的final相似：都禁止为变量重新赋值，但允许更改对象的内部状态。

但是const val不太行。

变量命名法建议采用驼峰命名法camelCase：从第二个单词开始每词首字母大写。

而对于const val声明的常量，Kotlin 社区通常建议使用全大写字母，单词之间用 下划线分隔。

Data types 数据类型

type inference 类型推理

kotlin会在初始化时自动确定变量类型，称作类型推理。

也可以自行指定类型，如

1
2

val text: String = "Hello World!"
val n: Int = 1

声明变量时必须有类型，即类型推理或自行指定类型。

如果看到type mismatch错误，则意味着为变量分配了不合适的内容。变量类型不能自动更改。
